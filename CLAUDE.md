# Unlisted: project context for Claude Code

## What this is
Unlisted (working name, may change) sells curated lists of UK firms that job seekers can cold-contact. Audience: graduates first, then career changers and experienced professionals. Marketed on TikTok and LinkedIn. Two equal partners run it as a low-cost side business.

## Product decisions (fixed)
- One plan: £9.99 a month, all 11 lists, cancel anytime. No per-sector plans.
- 11 lists: Investment and trading; Banking and capital markets; Wealth management; Private equity and venture capital; Insurance; Consulting; Fintech and payments; Tech and data; Energy; Accounting; Law.
- Each firm: name, type, size band, town, website, contact or careers page URL. Never sell emails, phone numbers or named people.
- Free sample: one firm per list per week, by email.
- Each download includes a tracker tab and five message templates.
- Monthly data refresh.
- Competitor: North Search (£9.99 a month, one plan, 8 sectors, outside London). We are UK-wide including London.

## Tech rules
- Website only, no app. Plain HTML, CSS and JS. `index.html` is generated by `node build.mjs`; edit copy and data there.
- No paid tools. Hosting: Cloudflare Pages (free). Waitlist: Pages Function `functions/api/waitlist.js` with a KV namespace bound as `WAITLIST`.
- Payments: Stripe Checkout (subscription) and the Stripe customer portal. Test mode first.
- Members area: email-link login, check the Stripe subscription is active, serve list files from private storage. Keep it minimal.
- Never commit secrets. Stripe keys and other secrets go in Cloudflare environment variables only.

## Design rules
- Brand colour is purple (#6D28D9) by the owner's choice. Keep it even though Taste Skill flags violet.
- Design skills are installed in `.agents/skills`: `design-taste-frontend` (Taste Skill), `impeccable`, and Emil Kowalski's skills (`emil-design-eng`, animation skills). Follow them for any UI work.
- Check UI changes with `node .agents/skills/design-taste-frontend/scripts/lint.mjs index.html css js` and `inspect.mjs index.html` (needs Chrome; set `CHROME_PATH`). Fix every FAIL except the accepted purple one.
- British English. Plain, short copy. No invented proof (no fake users, quotes or stats).

## Legal guardrails
- Show price, monthly renewal and how to cancel before payment. Online cancellation. Build to the UK DMCC subscription rules (proposed from 1 January 2027).
- 14-day cancellation waiver tickbox for immediate access.
- Do not imply endorsement by Companies House, the FCA or the SRA. Credit data sources on `/sources`.
- Do not use FCA-sourced data until the re-use licence is confirmed.
- Waitlist emails: opt-in only, unsubscribe link in every email.
