# Unlisted site

Static site: `public/index.html` and the legal pages `public/{terms,privacy,cookies,sources}/index.html`, plus `sitemap.xml` and `robots.txt` (all generated by `node build.mjs`), `public/css/site.css`, `public/js/site.js`, and a Cloudflare Worker at `src/worker.js` (config in `wrangler.jsonc`) for the waitlist form.

## Run and check
- Edit copy, example rows and legal text in `build.mjs`, then `node build.mjs` (it warns about unfilled legal placeholders).
- `npm run build` is the deploy build: it fails while any `{{PLACEHOLDER}}` is left. `npm run build -- --allow-placeholders` overrides that for previews.
- Config at the top of `build.mjs`: `LEGAL` placeholders, `SITE_URL` (swap for the real domain), `STRIPE_LIVE`, `LEGAL_NOINDEX`.
- Contact: unlisted.joblist@gmail.com. On the site it is joined by `js/site.js` from two parts, with a `<noscript>` fallback.
- Preview the static page: `npx serve public` (the form needs the Worker, see below).
- Design checks: `node .agents/skills/design-taste-frontend/scripts/lint.mjs public/index.html public/css public/js` and `.../inspect.mjs public/index.html` (needs Node 22+ and Chrome; set `CHROME_PATH`).

## Deploy (free)
Cloudflare Worker with static assets (not Pages), deployed by Workers Builds from GitHub on every push. `wrangler.jsonc` sets the entry (`src/worker.js`), the assets folder (`public/`) and the `WAITLIST` KV binding. There is no build command: run `node build.mjs` and commit `public/index.html`.

- Local test with the real Worker and a simulated KV: `npx wrangler dev --local`, then open http://localhost:8787.
- Other branches get a preview URL if non-production branch builds are on (Worker settings, Builds).
