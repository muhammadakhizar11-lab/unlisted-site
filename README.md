# Unlisted site

Static site: `index.html` (generated by `node build.mjs`), `css/site.css`, `js/site.js`, and a Cloudflare Pages Function at `functions/api/waitlist.js` for the waitlist form.

## Run and check
- Edit copy and example rows in `build.mjs`, then `node build.mjs`.
- Preview: `npx serve .` (or open `index.html`).
- Design checks: `node .agents/skills/design-taste-frontend/scripts/lint.mjs index.html css js` and `.../inspect.mjs index.html` (needs Node 22+ and Chrome; set `CHROME_PATH`).

## Deploy (free)
Cloudflare Pages, connect the repo, no build command, output folder `/`. Create a KV namespace and bind it as `WAITLIST` for the form.
